# EventosYCatering

Landing de SushiClub Eventos & Catering.

## Entrega para sistemas

La carpeta `web/` contiene el sitio estatico compilado y listo para subir.
Abrir o publicar `web/index.html`, no `src/static/index.html`.

## Desarrollo

```bash
npm ci
npm run dev
```

Servidor local: http://127.0.0.1:4173/

## Build

```bash
npm run build
```

El build genera la salida final en `dist/`.
